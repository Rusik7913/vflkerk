# Ням-Ням: Конфетный хаос — Deluxe

Оригинальная Android puzzle-игра в духе физической игры про конфеты, но со своими персонажами, интерфейсом и уровнями.

## Что внутри

- 15 стартовых уровней с процедурными вариантами механик
- физика конфеты и верёвок
- перерезание верёвок пальцем
- пузыри
- шипы
- 3 звезды на уровень
- монеты и сохранение прогресса
- магазин
- экран уровней
- настройки
- пауза / победа / проигрыш
- частицы и свечение
- portrait, Android 6.0+
- GitHub Actions для сборки APK

## Сборка

В GitHub Actions запусти:

`Build Nyam-Nyam → Run workflow`

APK появится в Artifacts как `Nyam-Nyam-APK`.


## Управление
- **ПЕРЕРЕЗАТЬ** — перерезать активную верёвку.
- Можно также провести пальцем по самой верёвке.
- Конфета раскачивается на верёвке, поэтому важно выбрать момент разреза.
- Если конфета улетела за экран, уровень можно повторить.
